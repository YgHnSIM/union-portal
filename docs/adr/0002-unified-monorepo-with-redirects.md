# 신규 단일 통합 모노레포 채택 및 기존 저장소 리다이렉트

회계(`YgHnSIM/accounting`)와 공개 자료실(`YgHnSIM/workplace`)을 별도 저장소로 유지하거나 한쪽에 흡수하지 않고, 신규 단일 통합 모노레포(`YgHnSIM/union-portal`)를 구축해 조직·회계·자료실 3개 컨텍스트를 통합한다. 기존 두 저장소 모두 한쪽 기능에 치우친 이름과 구조를 갖고 있어 종합 노조 관리 시스템의 그릇으로 부적합하며, 통합 개인정보 경계와 단일 빌드·검증 파이프라인을 처음부터 일관되게 설계하기 위함이다.

## Considered Options

- **`workplace` 저장소에 회계 흡수**: 기존 공유 URL·SEO를 그대로 유지할 수 있으나, 저장소 명칭·구조가 자료실 중심이고 기존 Git 이력과 이질적인 파이프라인을 떠안게 된다.
- **두 저장소 분리 유지 및 포털 셸 연계**: 인명 마스터·비식별 검증·회의록-재정 연계를 저장소 경계 너머로 동기화해야 해 이중 관리와 수치 불일치가 남는다.

## Consequences

- 통합 포털 배포 완료 후 기존 `accounting`·`workplace` GitHub Pages에는 기존 공유 링크가 깨지지 않도록 경로 매핑 리다이렉트를 유지한다.
- 다중 컨텍스트 구조(`GLOSSARY-MAP.md` + 컨텍스트별 `GLOSSARY.md` + 루트 `docs/adr/`)를 신규 저장소 표준으로 사용한다.
